
# QuickNotes

QuickNotes is a simple, responsive note-taking web application that helps users record, organize, search, and manage their notes. Users can categorize notes as Personal, Work, or Study, delete notes they no longer need, and keep their notes saved in the browser using localStorage.

## Features

- Add notes with text and a selected category.
- Organize notes into Personal, Work, and Study categories.
- Validate notes to prevent empty entries and notes longer than 200 characters.
- Delete individual notes.
- Search notes using case-insensitive text matching.
- Display the correct number of saved notes.
- Save notes in localStorage so they remain after a page refresh.
- Responsive design for desktop computers, tablets, and mobile phones.
- Clear error messages and a simple, user-friendly interface.

## How to Run the Project Locally

1. Download or clone this repository to your computer.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser, or use a local development server such as the VS Code Live Server extension.
4. Add notes, select categories, search, and delete notes.
5. Refresh the page to confirm that saved notes remain available.

No additional libraries or packages are required.

## Technologies Used

- HTML5 for page structure.
- CSS3 for styling and responsive layout.
- JavaScript for note management and validation.
- Browser localStorage for data persistence.
- Git and GitHub for version control and hosting.
